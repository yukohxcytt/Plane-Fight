# Plane Fight

基于 EasyX 图形库的 2D 飞机大战，纯 C 语言实现。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 上下左右移动 |
| 空格 | 发射子弹 |

## 功能

- 自机四向移动，限制在窗口边界内
- 敌机按固定间隔随机刷新，同屏上限 8 架，飞出底部自动回收
- 子弹对象池，最多同时 10 发，飞出顶部自动回收
- AABB 碰撞检测，击毁敌机 +100 分
- 撞机后弹窗询问是否重新开始，选择否则退出
- 背景音乐 + 发射音效

## 编译

依赖 Visual Studio 2022 及以上，需要安装 EasyX 图形库。

1. 用 Visual Studio 打开 `Plane Fight.slnx`
2. 配置选 `x64`，按 `F5` 运行

## 目录结构

```
Plane Fight.slnx          解决方案
Plane Fight/
  class1.cpp              全部游戏逻辑
  Plane Fight.vcxproj     工程配置
  img/res/                贴图与音效素材
```

## 实现要点

- 子弹与敌机的增删统一用「前移覆盖 + 长度回写」的方式管理，避免数组出现空洞
- 循环中删除元素后必须重新检查当前位置，否则补位上来的元素会被跳过
- 图像使用 `SRCAND` 贴图，素材底色为纯白，白底部分与背景相与后不可见

## 素材声明
