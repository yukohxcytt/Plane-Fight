# Plane Fight
>**这是我第一个用C语言写的小项目，也是我目前写过行数最多，最~~复杂~~的程序**

## 编译环境
本程序需要使用VS Studio运行

## 素材来源以及教程
我是跟着B站[这个视频](https://www.bilibili.com/video/BV1fktqz4Eev/?spm_id_from=333.1007.top_right_bar_window_default_collection.content.click&vd_source=0358a01fbcbc03800358d9229ffdadea)学的，
同时使用dsh辅助，如修改视频中错误的地方，优化相关代码。原始素材是从[@lytxddn8787](https://github.com/lytxddn8787)的[飞机大战仓库](https://github.com/lytxddn8787/c-FlaneFight)中获取的，
然后使用ai将素材都修改为了白底，而其中子弹的发射音效是由dsh生成的。
